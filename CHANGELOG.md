# Changelog

## 1.1.0

First public release.

- F10 menu: money, casino tokens, needs, stamina, intelligence, sympathy, followers, subs
- Item browser with search, categories and amounts; mod items included
- Color picker for colorable items (palette, RGB sliders, per color slot)
- Inventory view with single, stack and bulk removal; Keep equipped switch
- Freeze needs, infinite stamina, climax lock (restores original values when switched off)
- Draggable, resizable, layered windows with animations, styled like the game
- The game ignores clicks and keys while the menu is open
